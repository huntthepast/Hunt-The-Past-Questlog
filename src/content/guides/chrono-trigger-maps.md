The two maps above are placeholders drawn to show the layout: upload your own images from the admin (**Images & gallery** in the guide editor), add each one to the gallery with the area name, and they appear here as a wall of thumbnails with a full-screen viewer.

## How the maps are organised

- One image per area, named after the area, in the order you visit them.
- The walkthrough embeds the same files inline, so a fix to a map shows up in both places.
- **Download zip** in the admin bundles the gallery; attach that file to a GitHub release and put the asset link under **Downloads** so it is served by GitHub instead of the site.
