All codes are entered on the **title screen** while "PRESS START" is flashing. Do them before the demo starts.

## Level Select

| Input | Effect |
| --- | --- |
| Up, Down, Left, Right | A chime plays if the code registered |
| Hold **A** and press **Start** | Opens the level select / sound test menu |

## Debug Mode

Enter this instead of the level-select code:

1. Up, C, Down, C, Left, C, Right, C
2. Hold **A** and press **Start**

In game, press **B** to turn Sonic into a placeable object, **A** to cycle objects and **C** to place them. Press **B** again to go back to Sonic. Ring counter turns into coordinates while debug is on.

## Sound Test Easter Egg

From the level-select menu, play sounds **01, 09, 09, 02, 01, 01, 02, 04** in that order and then start any level. Enjoy. [Chrono Trigger - Items](/guides/chrono-trigger-items)

## Notes

- Achievements on RetroAchievements are disabled while debug mode is active, so keep the two runs separate.
- These codes only work on the original cartridge version, not on the later mobile/remaster ports.
